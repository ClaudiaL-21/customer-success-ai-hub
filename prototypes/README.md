# Interactive prototypes (backup)

Static click-through prototypes of the Customer Success AI Hub. They are built from real screenshots of the running app with clickable hotspots and guided tours.

| Folder | What it shows | Live version |
|---|---|---|
| [hub/](hub/index.html) | Hub tour, AI feature tour and email flow tour | https://claude.ai/artifact/UHd4SESuoxqyHK8YM7ZDtb |
| [qbr/](qbr/index.html) | QBR prototype with adoption simulation | https://claude.ai/artifact/FkAoRy42trDBE2P6rb7ViY |

The live versions are the ones to share. These folders are a backup so the prototypes survive if a hosted page is removed.

To open one locally, double-click its `index.html`. The pages need no server and no dependencies. All data in the screenshots is fictional.
